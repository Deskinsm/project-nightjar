# Recreational Flight Readiness Checklist

This is an internal project checklist, not legal advice.

## Operator

- [ ] TRUST completion certificate stored privately
- [ ] Certificate accessible during recreational operations
- [ ] Registration status determined from aircraft weight and operation
- [ ] Remote ID applicability reviewed
- [ ] Current airspace requirements checked before each flight
- [ ] Community-Based Organization safety guidelines selected

## Aircraft

- [ ] Flight controller configured
- [ ] Return-to-home tested
- [ ] Battery failsafe tested
- [ ] Geofence configured
- [ ] Manual RC override verified
- [ ] Propellers removed during bench testing
- [ ] Physical kill/disarm procedure rehearsed

## Mission

- [ ] Recreational purpose confirmed
- [ ] Visual line of sight maintained
- [ ] Weather and local conditions reviewed
- [ ] Takeoff and landing area controlled
- [ ] Mission policy approved
- [ ] Human operator ready to intervene
